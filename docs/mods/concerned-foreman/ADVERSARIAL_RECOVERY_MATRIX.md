# Adversarial recovery matrix (#287)

#287 asks that every required failure case has **a test and a stated expected behaviour**, and that no case
resolves by guessing. This file is that list, so the claim can be checked against the tree rather than against
an issue comment. Every test named here was confirmed to exist on `main` when the file was written, and each
"expected behaviour" cell says only what its tests assert. A rename that breaks a row should update the row.

**The invariant #287 protects:** container + reservations + placed cost is unchanged across any sequence of
failures. Nothing is conjured and nothing is lost silently. When the runtime cannot prove what happened, it stops
with a repairable journal entry and a readable message instead of guessing.

**How the tests check it.** `CooperationLoopTests.AssertInvariants` checks, after its steps, that every gathered
unit is recorded in exactly one of pack, cart or chest. That includes once after a hauler reload. It deliberately
skips that equality while a transfer is uncertain, or when called with `materialConserved: false`. The collection
loop has its own equivalent, `CollectionLoopTests.AssertConserved`, and
`CollectionLoopTests.TheConservationCheckFailsWhenTheRecordCreditsWhatWasAskedRatherThanWhatMoved` proves that
check can fail. Construction conservation (reservations and placed cost) is asserted inside the
`BuildRecoveryTests` named below.

Test files: `src/Shared.Settlement.Tests/` unless the row says `Foreman.Tests`
(`src/ConcernedForeman.Tests/`).
