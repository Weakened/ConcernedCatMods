# Contributing to ConcernedCatMods

Thanks for helping improve The Concerned Cat mods.

Start here:

1. `docs/NAMING_CONVENTIONS.md`
2. `docs/DEVELOPMENT.md`
3. `docs/mods/concerned-cartographer/DEVELOPER_GUIDE.md`
4. `docs/mods/concerned-cartographer/CODEBASE_GUIDE.md`
5. the relevant GitHub issue

## Core expectations

- Keep one issue/feature/fix per focused branch.
- Add tests for deterministic behavior.
- Do not commit game/vendor DLLs.
- Do not mutate Valheim world saves.
- Preserve backward compatibility or provide a migration.
- Fail closed when fragile game APIs are unavailable.
- Update docs when behavior/data formats change.
- Provide real game evidence for game-specific claims.

## AI-assisted contributions

Material AI use is allowed but must be disclosed in the PR.

You remain responsible for reviewing and validating what you submit.

See `docs/mods/concerned-cartographer/AI_DEVELOPMENT.md`.

## Attribution and license

By contributing code, you are submitting it for inclusion under the repository's current license unless a separate agreement is explicitly made.

Do not submit code/assets you do not have the right to contribute.

Original project attribution is documented in `NOTICE.md`.
