## 0.1.0 (Internal — unreleased)

**Product bootstrap (CT-001).** Concerned Teamster exists as an independent product in the ConcernedCatMods monorepo: its own plugin (`com.theconcernedcat.valheim.concernedteamster`), configuration binding, pure-domain test project, package metadata, and repository validation. The plugin logs its identity, environment banner, and effective configuration, and does nothing else — no cart observation, no gameplay behavior, no world writes.
