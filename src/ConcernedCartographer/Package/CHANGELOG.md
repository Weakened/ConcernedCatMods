# Changelog

## 0.1.0

- Initial alpha road-survey implementation.
- Detect dirt Pathen and paved terrain beneath the local player.
- Draw independent dirt and paved Jötunn map overlays.
- Persist road strokes in per-world sidecar files.
- Add spacing, maximum-gap, autosave, threshold, line-width, and diagnostic configuration.

### Known limitations

- Only traversed roads are discovered.
- No multiplayer synchronization.
- No in-place pin editor or expanded legend yet.
